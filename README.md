# 大健康智能管家（Health AI Assistant）

一款以「自然语言对话」为核心的 AI 健康陪伴平台。用户只需像聊天一样说出自己的需求，就能无缝串联起**预问诊、挂号、买药、查医保、看报告**等全链路医疗场景，无需在层层菜单里来回翻找。

---

## ✨ 核心特色

- **智能对话驱动**：弱化传统的功能菜单，用「对话框即主界面」。用户的一句自然语言（如“我有点失眠”“帮我查一下医保余额”），会被自动理解并直达对应的功能模块。
- **长辈模式（适老化）**：一键切换「长辈模式」，全局放大字号、加粗字体、增强对比度，并优先引导语音交互，帮助银发族跨越数字鸿沟。
- **医疗科技美学**：以湖蓝 / 翠绿为主色调，传递宁静、治愈与专业的视觉感受。

---

## 🚀 主要功能

### 1. 全局智能对话

整个 App 的交互底座，支持**文字、语音、图片**多种输入方式：

- 智能识别用户的意图，自动跳转到对应功能。
- 根据当前时间和用户画像，动态推荐追问（如“想开点中药调理身体该挂什么科？”）。
- 对话记录贯穿始终，切换功能不丢失上下文。

### 2. AI 智能诊室（智能预问诊）

- **三步引导**：选咨询人 → 描述症状 → 输出诊疗建议，流程清晰合规。
- **家庭健康档案**：可为本人、父母等家庭成员分别建档，快速切换。
- **急症预警**：识别到危险症状时优先给出安全提醒。
- **免责提示**：显著标注 AI 建议不替代真实医生面诊。

### 3. 健康数据看板（健康小目标）

- **体征数据**：展示步数、睡眠、心率、活动热量等日常健康数据。
- **每日打卡**：喝水、吃药、运动等任务进度追踪，帮助养成健康习惯。

### 4. 药管家（医药闭环）

- **拍药盒识药**：拍摄药品包装，自动识别药品信息，提供用药科普与比价。
- **扫追溯码**：识别药品追溯码，实现防伪验真与过期预警。
- **服药提醒**：以清晰卡片展示近期服药计划，支持一键“已打卡”。
- **家庭药箱**：统一管理家中常备药品与有效期。

### 5. 医保管家（查医保）

- **电子医保凭证**：直观展示医保卡信息，余额支持“小眼睛”一键隐藏，保护隐私。
- **多维服务入口**：消费记录、年度缴费、共济管理、异地备案，一站式直达。
- **扫码支付**：一键调出支付条码，模拟线下药店 / 医院结算。

### 6. 就医服务 & 检查报告夹

- **智能导诊挂号**：搜索全国三甲医院，结合定位推荐附近医疗机构并显示距离。
- **化验单 AI 解读**：拍照上传血常规、CT 等报告，自动提取异常指标并给出生活建议。

---

## 🔒 隐私与安全

- 报告、药盒等图片默认**模糊展示**，需按住才可查看。
- 涉及个人身份信息的内容统一脱敏处理，不保存原始图片。
