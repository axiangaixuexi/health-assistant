# 急症分诊技能（Emergency Triage Skill）

快速、确定性的模式匹配安全关卡，在任何 LLM 对症状输入进行推理**之前**运行。
对自由文本做 ACLS/ATLS 危险信号检查，并返回一条强制动作，零幻觉风险（纯规则匹配）。

## 响应级别

| 级别 | 含义 | Agent 必须执行的动作 |
|-------|---------|----------------------|
| CRITICAL | 可能危及生命——立即拨打 120 | 首行输出“请立即拨打120”；不要继续正常问诊 |
| URGENT | 需在 1–2 小时内前往急诊 | 建议立即就医 |
| PROMPT | 需当日门诊就诊 | 建议尽快预约 |
| NON_URGENT | 可常规处理 | 继续正常问诊流程 |

## 必需输入

- `symptoms_text` —— 用户描述的症状原文

## 可选输入

- `age` —— 用于调节儿科与老年阈值
- `duration_minutes` —— 症状起病急缓（突发 < 30 分钟 = 严重程度更高）

## 可识别的危险信号

- 心脏：胸痛、心悸伴晕厥、疑似心梗
- 神经：卒中征象（FAST）、剧烈头痛、抽搐、意识丧失
- 呼吸：严重呼吸困难、气道梗阻、过敏性休克
- 出血：无法控制的大出血、呕血
- 儿科：热性惊厥、婴儿呼吸窘迫
- 代谢：疑似糖尿病酮症酸中毒、严重低血糖

## Agent 使用说明

- 首先调用本技能——先于 symptom_scorer 或任何其他推理
- 若 `level == "CRITICAL"`：立即输出急救提示；不要追问
- 始终将 `safety_message` 字段原样作为回复的开场白
- 将 `action` 字段作为清晰、醒目的行动指引展示
